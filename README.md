# ProofLab — система доказательства корректности алгоритмов

Курсовой проект по дисциплине «Интернет-программирование».

> **Тема:** «Разработка системы автоматического доказательства корректности алгоритмов на основе интерактивного theorem proving».

Полный план архитектуры, функций и этапов разработки находится в [DESIGN.md](DESIGN.md).

## Текущий этап

Создан первый вертикальный срез приложения:

- FastAPI API с каталогом алгоритмов;
- React + TypeScript интерфейс каталога и рабочего места доказательства;
- контролируемый сервис запуска Lean 4 с тайм-аутом;
- настоящая Lean-формализация свойства алгоритма поиска максимума: каждый входной элемент не превышает вычисленного результата;
- корректная обработка отсутствующего proof engine.

Поддерживаются учебные карточки алгоритмов поиска максимума в списке и линейного поиска. Для поиска максимума доступна предметная Lean-модель; формализации линейного поиска, аутентификация, база данных и история попыток будут добавлены следующими этапами.

## Локальный запуск

### 1. Backend

Требуется Python 3.11 или новее.

```sh
cd backend
py -m venv .venv
.venv\Scripts\activate
py -m pip install -r requirements.txt
py -m uvicorn app.main:app --reload --port 8000
```

API будет доступен по адресу `http://localhost:8000`, интерактивная OpenAPI-документация — по адресу `http://localhost:8000/docs`.

### 2. Frontend

Требуется Node.js 22 или новее.

```sh
cd frontend
npm install
npm run dev
```

Vite выведет адрес локального интерфейса, обычно `http://localhost:5173`.

## Lean 4

Для фактического запуска доказательств требуется Lean 4. Проект использует Lean `4.35.0`, зафиксированный в [`lean/lean-toolchain`](lean/lean-toolchain). До его установки API возвращает честный статус `engine_unavailable`, а интерфейс отображает инструктивное сообщение вместо ложного результата.

После установки Lean должна быть доступна команда:

```sh
lake env lean --version
```

По умолчанию backend использует команду `lake env lean` и, при установке через elan, автоматически находит Lake в стандартном пользовательском каталоге. При необходимости команду можно изменить переменной окружения `LEAN_COMMAND`.

Проверка формального модуля:

```sh
cd lean
lake build
```
